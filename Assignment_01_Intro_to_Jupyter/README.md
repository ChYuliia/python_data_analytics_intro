# Assignment 01: Introduction to Jupyter & Process Review

This introductory assignment establishes the foundational technical environment for the **Python for Data Analytics** coursework (CIS 2266 at Sinclair Community College). The lab focuses on mastering the interactive Jupyter Notebook environment, executing code cells, managing markdown documentation, handling kernel states, and understanding asynchronous outputs.

* **Language:** Python 3+
* **Environment:** Jupyter Notebook (`.ipynb`) / IPython Kernel

## Workflow & Core Concepts

* **Environment Navigation:**  
  Explored the structure of Jupyter Notebooks, differentiating between code execution cells, formatted Markdown cells, and raw text cells.

* **Execution Shortcuts:**  
  Practiced running code using `Shift-Enter`, inserting new cells with `Alt-Enter`, and managing command/edit modes.

* **Kernel & Output Management:**  
  Observed asynchronous output rendering, handled large output scrolling, and reviewed methods for restarting kernels to reset computation states.

## How to Run

1. Open **Anaconda Prompt** (or your standard terminal/Command Prompt).

2. Navigate to the assignment directory:
   ```bash
   cd python_data_analytics_intro/Assignment_01_Intro_to_Jupyter
   ```

3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

4. In the browser window that opens automatically, navigate to the `notebooks/` folder and open `Assignment_01_Intro_to_Jupyter.ipynb`.

5. Run through the cells sequentially to review the interactive environment features.
