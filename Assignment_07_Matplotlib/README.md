# Assignment 07: Data Visualization with Matplotlib

This assignment covers foundational data visualization techniques using the Matplotlib library based on the course curriculum requirements. The project implements customized line plots with specific styles and markers, vertical and horizontal bar charts (including multiseries comparisons), proportional pie charts, and styled scatter plots.

---

## Technical Stack & Environment

* **Language:** Python 3+
* **Libraries:** Matplotlib, NumPy
* **Environment:** Jupyter Notebook (`.ipynb`)
* **Reference Curriculum:** CIS 2266 / Python for Data Analysis / Data Visualization with Matplotlib

## Workflow & Core Concepts

* **Line Plots & Styling:**  
  Generated multi-series line charts with custom colors, dashed/solid line styles, line widths, and explicit marker shapes and sizes.

* **Bar Charts (Vertical & Horizontal):**  
  Constructed single and multi-series bar charts using explicit width, alignment, and grid configurations to compare categorical and temporal datasets.

* **Proportional Pie Charts:**  
  Created structured pie charts featuring custom color palettes, custom slice labels, percentage formatting, and rotated starting angles.

* **Scatter Plots:**  
  Produced customized scatter plots incorporating distinct marker styles, color mapping, sizing parameters, and edge styling.

## How to Run

1. Open **Anaconda Prompt** (or your standard terminal/Command Prompt).

2. Navigate to the assignment directory:
   ```bash
   cd python_data_analytics_intro/Assignment_07_Matplotlib
   ```

3. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. In the browser window that opens automatically, navigate to the `notebooks/` folder and open `Assignment\_07\_Matplotlib.ipynb`.

5. Run all cells sequentially to render the plots and verify visual outputs.
